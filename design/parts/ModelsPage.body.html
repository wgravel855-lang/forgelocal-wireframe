How a row gets here

A profile is admitted only after the full agent loop passes on real hardware. Failures are published on the row rather than removed from the catalog. Read the test harness notes
01 Pin the whole unit Runtime build, model tag, quantization, context, sampling, tool schema, prompt.
02 Run the agent suite Edits, patches, shell, Git reads, schema repair, compaction, recovery.
03 Repeat per machine class Fit is stated per hardware envelope, never as a single global claim.
04 Publish the failures too Each failed check becomes the known limit shown on the card in the app.
