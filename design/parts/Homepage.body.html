It does the memory arithmetic for you

Quantized weights, plus the key-value cache for the context you want, plus runtime overhead, against the memory your machine actually has. ForgeLocal recommends one profile and shows the sum. Quantization, context and offload stay behind Advanced until you want them.

You see the exact command

Every risky action stops and explains itself: what runs, why the task needs it, where it runs, what it can reach, and whether it can be undone. Remembering a permission scopes it to that exact command in that project, and you can revoke it in settings. There is no allow-everything button.
