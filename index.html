Wireframe

ForgeLocal

A local coding agent: it detects what the machine can run, installs a suitable open model, gives that model bounded coding tools, and keeps the whole thing reviewable. Greybox screens, not a build.

Workspace

Rebuilt to the screen map: conversation-first, near-black shell.
No permanent file tree, terminal, diff or preview. Sidebar 256px, readable column 800px, context drawer hidden until there is something to inspect (see Change review, where the sidebar has collapsed to make room).
Completed low-risk events collapse to one quiet line. The current event stays expanded. Permission cards stay expanded until answered and nothing runs behind them.
Still to build on this page: recovery states, My Models, Explore, runtime health, automations, tools, settings.

Superseded

Do not build from this page.
These were drawn to the first blueprint, before the screen map locked the workspace as conversation-first. They use a permanent three-panel IDE layout with a task-state rail beside every conversation, which the map rules out: "Do not begin from an IDE layout."
