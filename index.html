Wireframe

ForgeLocal

A local coding agent: it detects what the machine can run, installs a suitable open model, gives that model bounded coding tools, and keeps the whole thing reviewable. Greybox screens, not a build.

Workspace

Conversation-first. Sidebar 248px collapsing to nothing, top bar 48px, reading column 792px, composer radius 16px. No permanent file tree, terminal, diff or preview, and no bottom status bar.
Finished low-risk work collapses into one Working group with quiet rows; only the current action stays open. Permission requests, errors and anything needing attention stay expanded and stop execution behind them.
Model lives in the composer, context and permission mode in its options menu, project and branch in the project menu.
Verified with no horizontal overflow and WCAG AA contrast at 1920, 1440, 1366, 1024 and 768.

Onboarding

Five steps in the same dark shell as the workspace, down from eleven light ones.
Step 2 replaces the three equal recommendation cards with one recommended profile, a plain-language reason, and alternatives behind Compare other options. Model family, quantization and context stay behind Advanced.
Step 3 folds runtime install, model download and the capability self-test into one screen; the seven technical checks sit behind View details.
Step 5 is the real workspace, not a congratulations page.

Marketing site

Light surface. One primary Download action and one secondary See how it works; no fake prompt box in the hero.
