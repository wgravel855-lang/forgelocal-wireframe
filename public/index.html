Common questions.

Does ForgeLocal send my code anywhere?

Not when you run a local model. The model runs on your machine and reads only the project folder you select. If you later connect a cloud provider, that is a separate choice and the interface says which one a session is using.

Which computers are supported?

Windows 10 and 11, 64-bit. A discrete GPU with 8 GB or more gives the best experience, and smaller models run on CPU where one is not available. macOS and Linux are not available yet.

Do I need to understand model formats?

No. ForgeLocal reads your hardware and recommends one model. Quantization, context length and memory arithmetic are shown if you want them, and ignored safely if you do not.

Can I use a model I already downloaded?

Yes. Point ForgeLocal at an existing GGUF file and it will use it instead of downloading a second copy.

What can the agent change?

Files inside the project folder you chose, and nothing outside it. Commands, network access and anything destructive ask first, in every permission mode.

Can I undo its changes?

Every set of edits is reviewed as a diff before you keep it, and every file is snapshotted before it is written, so reverting restores exactly what was there.
