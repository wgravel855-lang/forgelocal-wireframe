Security

What it can reach, and what it cannot.

The honest version, including the part most local AI tools leave out: a permission prompt is not isolation. Here is where the boundary actually is today, and where it is going.

The execution boundary
Renders Window No file or shell access of its own
Validates Typed channel Every privileged call checks its sender
Decides Host services Owns tools, secrets, approvals, checkpoints
Acts on One project root Canonicalized before every single operation
Today this is a permission boundary, not a sandbox. Commands run as your Windows account, so an approved command can do anything your account can do. That is why destructive classes are blocked outright rather than merely prompted. A protected workspace mode, where the project runs in a container, is planned and is not shipped.
