How this is calculated

Total = quantized weights + KV cache + runtime overhead.

KV = 2 × layers(42) × kv_heads(8) × head_dim(256) × context × 2 bytes (f16)

Runtime overhead is taken as a flat 0.6 GB for llama.cpp. These are planning figures. Real usage varies with the runtime build, batch size and offload split, which is why ForgeLocal re-measures on your machine.
