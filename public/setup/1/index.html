Set up ForgeLocal Step 1 of 5

Your coding agent, running on this PC

ForgeLocal works on your own hardware by default. Your code and your prompts stay on this machine unless you connect a cloud provider yourself.

  • It reads your hardware to pick a model that will actually run well, rather than making you guess.
  • It only touches the project folder you choose, and asks before anything risky.
  • Every change is a diff you can keep or undo.
