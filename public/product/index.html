How it works

Five steps, then you are working

There is no configuration file to learn and no inference vocabulary to pick up. The parts that matter are shown when they matter.

  1. 01
    Read the machine

    CPU, memory, video memory, free disk and any runtime already installed. It happens inside the app, after you agree to it, and the reading stays on the device.

  2. 02
    Pick one profile

    Not a catalog to guess through. One recommendation with the arithmetic shown, and alternatives behind a disclosure.

  3. 03
    Install runtime and weights

    Runtime, model download and a capability self-test in one step, with pause, resume and a clear interrupted state.

  4. 04
    Choose a folder and a permission preset

    Project file access is limited to that folder by default. The preset decides how often the agent stops to ask.

  5. 05
    Work, then review

    Plan, edits, commands and tests appear as one quiet activity group. Changes arrive as a diff you keep or revert per file and per hunk.
