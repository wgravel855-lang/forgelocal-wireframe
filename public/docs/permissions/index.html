Permissions

The three presets, what is never allowed, and how to take an approval back.

5 min read · Describes the behaviour this build defines

The presets

A preset is chosen per project and decides how often the agent stops to ask. It can be changed later in Settings, under Permissions.

Ask every time
Approve every file write and every command, including reading files. Slow on purpose. Appropriate for a codebase you did not write.
Balanced
Edits and the project's own test and build commands run on their own. Installing packages, network access, Git writes and deletes ask first. This is the recommended default.
Autopilot
Edits, the project's own build and test commands, package installs and Git writes run without asking.

What always stops and asks

Four classes stop and ask in every preset, including Autopilot, and this cannot be turned off:

  • Network access beyond the package registry.
  • Reads of files matching a secret pattern, such as .env or a private key.
  • Deletes outside the project root.
  • System-wide changes.

A prompt is not a sandbox

This is the honest limit and it is worth being blunt about. A permission prompt asks before running a command. It does not isolate the process afterwards. A command you approve runs with your user account's privileges and can, in principle, reach anything that account can reach.

That is why the prompt shows the exact command rather than a summary of its category, and why the always-blocked classes exist even in the most permissive preset. If you need real isolation, run the project in a container or a virtual machine and point ForgeLocal at that.

Remembered approvals

Choosing Always allow at a prompt creates a durable rule scoped to that project and that command, not to your whole machine. Every rule made that way is listed in Settings under Permissions, with the scope it was granted at and a Revoke button.

Revoking does not break the command. The next time the agent needs it, it stops and asks again, and you can grant it again from that prompt.

If the list of remembered approvals ever contains something you do not recognise, revoking it costs nothing except one extra prompt later.
