Clone from Git

A repository you have not read is untrusted input. Cloning it does not run anything in it.

Start from a blueprint
Open an existing folder
Clone from Git
Repository URL
https://github.com/[owner]/[repo].git
Clone into, and the only folder the agent may touch
C:\Users\[you]\projects\[repo]
Browse
Branch default
Free space 248 GB on C:
Private repositories need credentials you set up in Settings, not here.
What happens after the clone
The files land on disk. Nothing is installed and no script in the repository runs.
Manifests are read to propose a start, test and preview command. You approve them before first use.
HEAD is recorded as the first checkpoint. Your working tree is never staged, reset or cleaned without permission.
A command written in the repository's own README is never executed just because the model read it there.
Note This is the one onboarding step that pulls arbitrary third-party content onto the machine, so it states the boundary rather than assuming the earlier permission screen covered it.
