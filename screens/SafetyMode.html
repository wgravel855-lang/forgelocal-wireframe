How much should it ask?

You can change this per project later. There is no mode that turns protections off.

Ask every time Approve every write and every command, including reading files and running tests.
Edit a file: asks npm test: asks git status: asks
Balanced Recommended
Routine edits and safe project commands run on their own. Installs, network access, secrets, deletes, Git writes and anything outside the project ask first.
Edit a file: runs npm test: runs npm install: asks git commit: asks
Autopilot Broader project actions run without asking. Destructive and system-wide operations stay blocked or still ask.
npm install: runs git commit: runs Delete outside project: blocked
Note A permission prompt is not sandbox isolation, and the copy here should never imply that it is. Protected workspace mode comes later.
